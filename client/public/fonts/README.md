# Self-hosted interface fonts

Generated by `python3 scripts/subset-misans.py` — do not edit by hand.

MiSans is Xiaomi's system typeface: a variable font with a weight axis from
150 to 700 and a full set of OpenType features (SS01-SS09, frac, sups, case,
vert, tnum, ...). It is free for commercial use and may be embedded in
products, but the font files themselves may not be sold on their own.

The subset keeps only the characters the interface renders, plus the extra
code points the font features substitute in. The glyph outlines are not
modified, and the weight axis and every feature survive.

To regenerate after adding new interface copy:

```bash
python3 scripts/subset-misans.py /Users/ch1rpy/Desktop/MiSans/可变字体/MiSansVF.ttf
```

The script needs fonttools and brotli:

```bash
python3 -m venv .live-test/fontenv
.live-test/fontenv/bin/pip install fonttools brotli
```
