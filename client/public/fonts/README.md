# Self-hosted interface fonts

Generated by `node scripts/subset-font.mjs` — do not edit by hand.

Noto Serif SC is used for interface headings only. User generated text
(persona names, diary entries, farewell letters, chat messages) is set in
the sans stack, so characters outside this subset are never an issue.

To regenerate after adding new interface copy:

```bash
node scripts/subset-font.mjs
```
