# Mirrai v1.1.0 — 微信官方通道

> 「不在身边的时候，TA 还在这里。」

## 这是什么

Mirrai 是一个开源自托管的 AI 陪伴应用：上传真实聊天记录，多阶段蒸馏引擎重建 TA 的数字分身 —— TA 的语气、TA 的口头禅、TA 突然变冷漠的时刻。以及一个同类产品都没有的东西：**毕业机制**，一个帮你好好告别的设计。

## 本版重点：微信通道换成微信官方 ClawBot

**零封号风险。** v1.0.0 的微信功能基于 Wechaty + wechat4u 非官方协议，微信检测到异常行为会封号 —— 仓库 issue #1 里就有人反馈「刚绑定就被封」。这一版整体换成微信官方「ClawBot」插件（腾讯 iLink 协议）：

- 直接在微信里和分身对话，Web 端与微信端共享同一套人设和记忆
- 扫码授权，不接触你的微信主号数据
- 1:1 私聊（官方限制：不能被他人添加、不能进群），聊天对象是你自己
- 微信内可直接切换分身：`/使用 <分身名>`、`/分身列表`、`/当前分身`、`/毕业`
- 仓库已完全移除 `wechaty` / `wechaty-puppet-wechat4u` 依赖

### ⚠️ 微信通道是**完全替换**，不是升级

- 需要微信 **8.0.70+**，且「我 → 设置 → 插件」里能看到「微信 ClawBot」入口（该功能正在灰度放量，iOS 优先，安卓与桌面端逐步开放）
- 旧的朋友绑定**不再有意义**（官方通道是 1:1 私聊，对话方就是账号本人），升级后需重新扫码，并在网页端设置一次默认分身

## 核心变更

### 🧠 情绪状态机改由 LLM 判定

关键词规则（"想你" → 思念）太脆。改成让 LLM 以**分身的语气**判断当前情绪，而不是按用户的措辞猜；LLM 调用失败时自动回退关键词规则。开关：`EMOTION_ENGINE=llm|heuristic`（默认 `llm`）。

### 🔐 密码改用 scrypt 哈希

原来是 SHA-256 —— 公开源码里哈希算法一目了然，撞库成本极低。现在用 scrypt（N=16384, r=8, p=1，16 字节随机盐，64 字节输出，恒时比较）。旧账号的 `salt:sha256hex` 格式仍可验证，并在**登录时自动升级**为 scrypt，无需重置密码。

### 🧬 人格蒸馏统一为一条 pipeline

之前存在两条并行的构建路径（单次 LLM 调用 + 贪婪正则抽 JSON，与多阶段 pipeline），行为不一致。现在统一走 `startPersonaDistillation()`，并补上了平衡括号扫描器（替代 `match(/\{[\s\S]*\}/)` —— 后者会被嵌套 JSON 截断）和结构化的人设规范化。

### 🪟 Windows 开箱即用版

和 macOS 版对等：内置 Node.js + PostgreSQL，双击安装包 → 开始菜单启动，**不用装数据库、不用管理员权限、不写注册表**。数据落在 `%APPDATA%\Mirrai`，卸载走标准的「应用和功能」。

启动时会弹一个**带进度条的窗口**，实时显示「正在初始化数据库 → 正在同步表结构 → 正在启动服务 → 已就绪」。首次启动要初始化数据库，可能需要一两分钟 —— 有进度条就不会以为卡死了。

CI 上有一条冒烟测试真的把它跑起来过：用一个普通用户（PostgreSQL 不允许管理员身份运行）初始化数据库、建表、起服务、确认 HTTP 有响应。

### 🔌 新增 Cheaper Inference 提供商

OpenAI 兼容协议，接入后共 12 家 LLM 提供商。（感谢 @aiapienthusiast，#18）

### 🔒 修复：auth.me 不再返回密码哈希

`auth.me` 之前返回整行 user（含 `passwordHash`、`openId`），改为显式白名单字段。

## 安装

- **macOS（Apple Silicon）**：下载下方 `Mirrai-macOS-arm64.dmg`，拖入 Applications，双击即用（内置 Node.js + PostgreSQL）
- **Windows（x64）**：下载下方 `Mirrai-Setup-x64.exe`，双击安装 —— 装完在开始菜单（或桌面）双击 `Mirrai` 即可。同样内置 Node.js + PostgreSQL，**不用装任何东西，不用管理员权限，不写注册表**
- **Docker**：`cp .env.example .env && docker compose up -d` → http://localhost:3000
- **源码**：见 [README 快速开始](https://github.com/Ch1rpy2613/Mirrai#快速开始)

> ⚠️ PostgreSQL 拒绝在 Windows 上以管理员身份运行。如果你是用提权的命令提示符启动的 `Mirrai.cmd`，换回普通用户再启动即可。
>
> 桌面版把数据放在 `~/Library/Application Support/Mirrai`（macOS）和 `%APPDATA%\Mirrai`（Windows），卸载就是删掉那个目录加上程序本身。

## 升级步骤

### 从 v1.0.0 升级：手动执行一次微信迁移

微信表结构有语义变更（绑定对象从「好友」变为「账号本人」），**请不要跑 `pnpm db:push`**，改为手动执行一次增量迁移：

```bash
psql "$DATABASE_URL" -f drizzle/0002_wechat_clawbot_channel.sql
```

该迁移是幂等的，重复执行安全。它会：

- 把 `wechat_bindings.wechatContactId` 重命名为 `wechatUserId`
- 停用旧的第三方好友绑定（数据保留，可在前端清理）
- 为 `bot_status` 枚举补上 `scaned` / `need_verifycode`
- 给 `wechat_bot_state` 补上 iLink 凭据与长轮询游标字段
- 加一条 `(userId, wechatUserId) WHERE isActive = true` 的部分唯一索引

**全新部署**（v1.0.0 之后第一次安装）不用管这一节 —— `pnpm db:push` 会一次性建出最终结构。

### 密码无需重置

旧密码照常能登录，会在登录时自动升级为 scrypt。
