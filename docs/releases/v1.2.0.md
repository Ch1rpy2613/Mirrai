# Mirrai v1.2.0 — 夜灯与晨纸

> 「不在身边的时候，TA 还在这里。」

## 这是什么

Mirrai 是一个开源自托管的 AI 陪伴应用：上传真实聊天记录，多阶段蒸馏引擎重建 TA 的数字分身 —— TA 的语气、TA 的口头禅、TA 突然变冷漠的时刻。以及一个同类产品都没有的东西：**毕业机制**，一个帮你好好告别的设计。

## 本版重点：整个界面重做

之前的界面有设计系统，但没落地。标题在顶栏、kicker 和大标题里说了三遍；区块标题和统计数字长得一模一样；留白不是设计出来的，是塌陷出来的；而且正文字体来自 Google Fonts CDN —— **在国内或离线环境下，87 处标题会全部退化成系统宋体，整个产品变形。**

这一版把它整个换掉：

### 🌓 两套主题，跟随系统

- **夜灯 Nocturne**（深色）：暖墨蓝底，琥珀金作唯一强调色
- **晨纸 Vellum**（浅色）：奶油纸底，墨青作主色、砖橘作强调

### 🔤 MiSans 全站接管

小米的可变字体，`wght` 轴 150–700 覆盖从 Thin 到 Heavy 的全部字重，**并完整保留 26 个 OpenType feature**（SS01–SS09、frac、sups、case、vert、tnum…）。

字体随应用一起分发，不再依赖任何 CDN：**一个 272KB 的子集**，只裁字符集、字形轮廓一字未改。等宽数字（`tnum`）全站开启，统计数字再叠 `ss04`（与汉字等高），成就进度用 `frac` 排成真分数。

### 📐 层级与密度

- 建立四级字阶，**统计数字改用无衬线 tabular**，绝不会被误读成标题
- 顶栏不再显示页面名，**一个标题全页只出现一次**
- 统计块、Tab 样式、图表配色全站统一成一套
- Lobby 放开宽度并改成两栏，「今日推荐」与「每日来信」并排
- 聊天里的情绪标签**只在情绪变化时出现**，不再每条都挂
- 图表去掉虚线网格与渐变填充，高度按内容自适应

### 🪟 桌面版：macOS 与 Windows 同时到位

- **macOS**：`Mirrai-macOS-arm64.dmg`
- **Windows**：`Mirrai-Setup-x64.exe` —— Inno Setup 安装包，不用装数据库、不用管理员权限、不写注册表

Windows 版启动时会弹一个**带进度条的窗口**，实时显示「正在初始化数据库 → 正在同步表结构 → 正在启动服务 → 已就绪」。首次启动要初始化数据库，可能需要一两分钟 —— 有进度条就不会以为卡死了。

CI 上有一条冒烟测试真的把它跑起来过：用一个普通用户（PostgreSQL 不允许管理员身份运行）初始化数据库、建表、起服务、确认 HTTP 有响应。

## 顺带修掉的

- **本地开发登录不上** —— 会话 cookie 设了 `SameSite=None` 却不带 `Secure`，浏览器在明文 http 下直接拒收；登录成功后 `invalidate()` 又不会真的重新拉取数据，落地页纹丝不动。现在本地也能正常登录。
- **`drizzle-kit migrate` 从来没成功过** —— 它依赖被 gitignore 的 `drizzle/meta/`，桌面包里没有，表建不出来。改用不依赖 journal 的 `drizzle-kit push`。
- **分身卡片上的内部字段**（"默契 41"）已删除；只对普通用户没有信息量的角色徽章不再显示。

## 相对 v1.1.0 的变化

- 界面全面重做：双主题、MiSans、字阶与密度统一
- macOS 与 Windows 安装包重新构建，包含 v1.1.0 的全部改动
- 修复本地开发的登录流程
- 修复桌面版的数据库初始化

## v1.1.0 已经带来的（仍在这一版里）

- **微信官方 ClawBot 通道**：从 Wechaty 私有协议迁到腾讯 iLink 协议，零封号风险
- **密码改用 scrypt 哈希**：旧 SHA-256 账号照常登录，登录时自动升级
- **情绪状态机改由 LLM 判定**：按分身的语气判断，而不是按用户的措辞猜
- **人格蒸馏统一为一条 pipeline**
- **Cheaper Inference 提供商**（12 家 LLM 提供商）
- **`auth.me` 不再返回密码哈希**

## 安装

- **macOS（Apple Silicon）**：下载下方 `Mirrai-macOS-arm64.dmg`，拖入 Applications，双击即用
- **Windows（x64）**：下载下方 `Mirrai-Setup-x64.exe`，双击安装即可
- **Docker**：`cp .env.example .env && docker compose up -d` → http://localhost:3000
- **源码**：见 [README 快速开始](https://github.com/Ch1rpy2613/Mirrai#快速开始)

> 微信通道需要微信 **8.0.70+** 且「我 → 设置 → 插件」里能看到「微信 ClawBot」入口（该功能正在灰度放量，iOS 优先）。

## 升级步骤

从 v1.1.0 升级的用户，如果用桌面版，重新下载安装即可（数据库会自己同步）。

源码用户如果之前跑过 `pnpm db:push`，**改用 `pnpm db:push` 之外的方式**：

```bash
psql "$DATABASE_URL" -f drizzle/0002_wechat_clawbot_channel.sql
```

该迁移是幂等的，重复执行安全。它会把 `wechat_bindings.wechatContactId` 重命名为 `wechatUserId`、停用旧的好友绑定、补上 `bot_status` 枚举值和 iLink 凭据字段。
