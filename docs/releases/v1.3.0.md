# Mirrai v1.3.0 — 灯亮着的时候

> 「不在身边的时候，TA 还在这里。」

## 这是什么

Mirrai 是一个开源自托管的 AI 陪伴应用：上传真实聊天记录，多阶段蒸馏引擎重建 TA 的数字分身 —— TA 的语气、TA 的口头禅、TA 突然变冷漠的时刻。以及一个同类产品都没有的东西：**毕业机制**，一个帮你好好告别的设计。

## 本版重点：把「说了很久」的三个承诺兑现

上一版把界面重做了一遍。这一版回头看代码，发现有几件事**界面说了、代码没做**。这一版把它们补上。

### 💬 回复现在是一个字一个字出现的

以前发一条消息，界面转圈，直到整段回复一次性出现 —— 那是假的流式。现在是真的：Server-Sent Events 逐 token 推过来，Markdown 在过程中就能渲染，中途还能按停。

改这件事的时候先做了一次重构：原本「组装上下文 → 调模型 → 落库 → 判情绪 → 算亲密度 → 看毕业」这套流程在四个地方各写了一遍（三个 tRPC 接口 + 微信通道）。现在收敛成 `server/chat/service.ts` 一份，网页、流式、微信、飞书全都走它 —— 记忆召回、安全层、毕业判定以后只需要改一处。

### 🧠 记忆终于会被想起来

`memory.autoExtract` 一直在抽记忆，抽出来的结果存进 `memories` 表 —— 然后**再也没被读过**。对话上下文里只有蒸馏产物里的那一段 `memories` 字段。

现在记忆会参与打分（关键词覆盖 45% + 时间新鲜度 25% + 类别权重 20% + 人工置顶 10%），最相关的几条进入上下文。中文用二元组匹配，不引入任何分词依赖。

还多了一个概念：**记忆锚点**（`category = "anchor"`）。锚点永远注入，并且带一条硬约束：

> 若对话需要引用锚点以外的具体事实，而记忆中没有记录，请表现为不确定，不要编造。

产品文档里把「记忆幻觉」列为三大挑战之一 —— 这是那个挑战的答案。

另外，超出上下文窗口的旧对话不再直接丢掉，而是压成**滚动摘要**存下来。

### 🛟 情感安全层

产品文档 §3.4 写了三类监测：单次对话超过 2 小时、单日超过 5 次、情绪词汇分析。代码里 **零实现**。现在有了。

危机识别在本地完成，不联网、不上报：命中自伤/自杀类表述时，分身会温和地「出戏」说一句关心的话，然后给出本地求助热线（12356、findahelpline.com、988……）。弱信号（「今天好累」）不会触发 —— 那只会变成噪音。

## 同时修掉的、行为与承诺不符的地方

这一版也顺手把一批「界面上能配、其实没生效」的问题修了。

| 问题 | 之前 | 现在 |
|---|---|---|
| **你在设置里配的 API Key** | 存进 `llm_configs` 表后**从来没有被任何调用读过** —— 注册表只认 `.env` | 按用户解析，保存即生效；密钥加密存储，列表接口只回传掩码 |
| **注销登录** | 只清 cookie，JWT 一年后才过期 | 令牌版本号机制，注销立刻失效 |
| **跨用户越权** | 别人的分身任务能被读到，别人的场景能被删 | 每个带标识符的查询都强制带 `userId` 谓词，TypeScript 层面强制调用方传参 |
| **上传目录** | 整个 `/uploads` 静态直出，聊天记录、照片、TTS 凭 URL 就能拿 | 按用户鉴权，路径里的归属段要和当前用户对得上 |
| **路径穿越** | 客户端传来的文件名直接拼进路径 | 文件名净化 + 路径包含性校验 |
| **无限流** | 登录接口和所有计费的 LLM 接口都没有限流 | 令牌桶限流，鉴权按 IP、LLM 按用户 |
| **CSRF** | Cookie 在 HTTPS 下 `SameSite=None`，无 Origin 校验 | 默认改回 `lax`，并加 Origin 校验（`SameSite=None` 需显式开启） |
| **删号留垃圾** | 注销时漏删日记、场景、蒸馏任务，且没有事务 | 单事务删全部 13 张表 |
| **迁移脚本** | `pnpm db:push` 依赖被 gitignore 的 `drizzle/meta/`，新克隆必然失败 | 改用 `drizzle-kit push`，并新增可幂等重跑的 `pnpm db:migrate` |

## 新增的能力

### ✨ 飞书通道

飞书的「使用长连接接收事件」（WebSocket）模式**不需要公网 IP、域名或 SSL 证书** —— 和微信通道一样，适合放在自己的机器上。两个通道共用同一套对话管线、指令和人设。

> ⚠️ 需要**企业自建应用**（长连接模式不支持商店应用），且应用要**发布并经管理员审批**后权限才生效。

### 📥 多源聊天记录采集

`skill-engine/tools/` 里那四个采集器（飞书 / 钉钉 / Slack / 邮件，合计 2800+ 行 Python）**从来没有被任何代码引用过**。现在接上了：统一的采集契约、进度回传、幂等导入。

### 🎴 SillyTavern 角色卡

分身可以导出成 SillyTavern 的 PNG v2 角色卡（含 `chara` chunk），别的工具能直接认；反过来也能把角色卡导回来。不引入任何新的 npm 依赖 —— PNG chunk 读写和 CRC32 都是自己实现的。

### 📝 引导式问卷

没有聊天记录也能创建分身。九步问答直接产出符合 7 层结构的人设，和蒸馏出来的分身用同一套下游逻辑。

### 📚 分身模板库

本地模板库 + 文件导入导出。**刻意不做远程市场** —— 产品的伦理框架写得很清楚：「系统不拥有、不出售、不分析用户的任何个人数据」。

### 🖥 PWA

可以安装到桌面或主屏了。Service Worker 只缓存应用外壳，`/api/**` 和 `/uploads/**` **一律 network-only** —— 你的对话不会被写进任何缓存。

### 🔔 主动提醒

纪念日、相识周年这类日子，分身会来找你说话。免打扰时段可配。

## 升级说明

### 源码用户

```bash
pnpm install
pnpm db:migrate    # 应用增量迁移（幂等，可重复运行）
pnpm build && pnpm start
```

新装的用户直接 `pnpm db:push` 一次建全量即可。

### 桌面版用户

重新下载安装包。数据库会在启动时自动同步。

### 一个需要你确认的设置

首次启动时，Mirrai 会自动创建一个本地管理员（用户名 `admin`，随机密码），并把凭据写到：

- macOS：`~/Library/Application Support/Mirrai/first-run-credentials.txt`
- Windows：`%APPDATA%\Mirrai\first-run-credentials.txt`

**请登录后尽快改掉这个密码。** 不想要自动创建就设 `MIRRAI_BOOTSTRAP_ADMIN=manual`。

## 伦理提醒

请仅上传你有权使用的聊天记录；对真实人物建模请获得对方同意。Mirrai 的目标是帮你完成告别，而不是替代真实的关系。

危机支持资源清单里的热线号码来自内置清单，**上线前请人工核对一次** —— 它们会变。清单在 `server/safety/resources.ts`，也可以用 `SAFETY_RESOURCES_FILE` 换成你自己的。
