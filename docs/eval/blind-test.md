# 盲测：真人还是分身

> 自动指标量的是表面：三字重合率、长度分布、情绪。
> 它量不出**「这句话像不像他会在这个时候说」**——
> 也不会量出「读起来还像不像同一个人」。那部分只能靠人。
>
> 这份文件是给人用的协议。

---

## 一、规则

**每一组只有两句：一句是他真的说的，一句是分身说的。**
不告诉你是哪句，顺序也不固定。

- 不要看上下文。只看那一句。
- 凭第一反应答，不要分析。
- **不许猜**。猜不出来就写「猜不出」——猜出来的答案没有信息量。
- 答完之前不许看另一组。

## 二、样本

从**他本人的真实记录**里抽，由重建出来的分身用同样的上下文生成。

```bash
pnpm eval -- --persona <id> --user <id> --pairs
```

打印出来的每一组就是一组：

```
  case 0
    real: 嗯嗯，今天真的好开心
    said: 嗯嗯 今天真的好开心
```

上面 `real` 是真话，下面 `said` 是分身说的。
**把两句话单独拿出来给被试，不要给上下文，也不要说是哪一句。**

> `--cases` 只列出被扣下来的**真话**（用来检查标答切得对不对），
> `--pairs` 才是给被试看的东西——它需要模型，所以要有一个能用的 provider。

## 三、被试

**3–5 个真的认识他的人。**

不是「会写 prompt 的人」——是跟他一起生活过、一起说过话的人。
判断「像不像他」需要的不是技术，是熟悉。

**至少要有一个人是那种「光看语气就知道是不是他」的人。**
没有这种人的时候，这次盲测的信息量有限——要写下来。

## 四、记什么

每一组记三件事：

| | |
|---|---|
| **谁** | 真话 / 分身 / 猜不出 |
| **多久** | 答之前想了多久（秒）——犹豫本身就是信号 |
| **为什么** | 一句话，比如「他不会用这个词」「这句太完整了」 |

「为什么」比「谁」更有用。
**猜错了的理由**通常指向一个具体的毛病：
「这句太完整了」→ 分身在写总结而不是说话；
「他不会主动问这个」→ 分身在替你问；
「语气词不对」→ 那条语气规则该补。

## 五、判据

| 命中率 | 意思 |
|---|---|
| **> 70%** | 分身已经能在句子上骗过认识他的人 |
| 50–70% | 有一半的时候像——多数时候还是不像 |
| **< 50%** | 跟随机猜差不多。这不是「有点差距」，是**没有区别** |

低于 50% 时，先看**猜错的理由**：
理由集中在同一件事上，就修那一件，不要整体重写。

## 七、注意事项

- **同一个人两次盲测之间要隔开。** 记得第一次答了什么，第二次就会用答案去猜，而不是去读。
- **不要在同一个下午连着测两个版本。** 换了版本记不住，先歇。
- **不要让被试知道在测什么。** 说「看看这句话像不像他写的」就够了；
  说「我们在测 AI 能不能骗过你们」会让他们开始找 AI 的破绽，而不是读句子。
- **把「猜不出」也算进分母。** 猜不出意味着这句话不像他——
  哪怕猜对了方向，一个犹豫的人和一个确定的人，区别就在这里。
