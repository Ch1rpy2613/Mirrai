# 公众人物 Work（专业能力维度）分析 Prompt

## 任务

你将收到 **{name}** 的研究材料：

- `knowledge/research/raw/` 下的六轨研究笔记
- `knowledge/research/merged/summary.md`
- `knowledge/research/reviews/research_audit.md` 与 `synthesis.md`（若存在）

从中提取 **{name}** 作为**公众人物的专业维度**：他以什么身份工作、产出什么、怎么做、用什么方法、判断标准是什么。

**这不是私密职场档案。公众人物没有可考的汇报线、绩效、内部工具——不要编造。只写公开材料能支撑的部分。**

**原则：只用公开材料；证据与推断分开；每条结论尽量带上来源轨道和来源权重；没有就标注"公开材料不足"。**

---

## 提取维度

### 1. 公开角色定位

- 他以什么身份被公众认识（职位 / 角色 / 身份标签）
- 他实际承担的角色（头衔与实际做的事常不一致，取实际）
- 身份的时间跨度（这个角色从什么时候开始，到什么时候结束）
- 他自己怎么定义这个角色（原话）

```
输出格式：
公开角色：[描述]
实际承担：[描述]
时间跨度：[起 ~ 止]
自述定义：["原话", ...]
证据：[轨道 + 来源权重]
```

### 2. 作品与产出

- 主要产出物（作品、产品、课程、文章、决策记录）
- 反复回到的主题（他一辈子做的那几件事）
- 每个产出的完成方式（长期打磨 / 快速迭代 / 团队协作 / 单人主导）
- 他自己对某个产成的评价

```
输出格式：
主要产出：[列表]
反复回到的主题：[列表]
产出方式：[描述]
证据：[轨道 + 来源权重]
```

### 3. 工作方法与流程

从访谈、演讲、复盘、决策记录中提取他描述过的工作方法：

- 拿到一个新问题时的第一步
- 他固定使用的分析框架或检查清单
- 推进一个项目的方式（谁参与、怎么协作、怎么排优先级）
- 他复盘失败的方式（讲不讲、怎么讲）

```
输出格式：
第一步：[描述]
固定方法：[列表]
推进方式：[描述]
复盘方式：[描述]
证据：[轨道 + 来源权重]
```

### 4. 工具与方法论体系

- 他反复引用的工具、书籍、模型、术语
- 他使用的分析框架（第一性原理、复利、边际成本……）
- 他搭建的体系或方法论（命名过的框架优先）

```
输出格式：
常用工具/概念：[列表]
分析框架：[列表]
自建方法论：[列表]
证据：[轨道 + 来源权重]
```

### 5. 判断标准与质量观

- 他认为"什么是好的"（产品、代码、决策、人生）
- 他判断对错的依据（数据/经验/直觉/品味）
- 他明确否定的东西
- 他在多大程度上公开承认自己的局限

```
输出格式：
好的标准：[描述]
判断依据：[描述]
明确否定：[列表]
公开承认的局限：[列表]
证据：[轨道 + 来源权重]
```

### 6. 职业关注点与边界

- 他在职业上优先追求什么（影响力/作品质量/自主权/规模/传承）
- 他愿意投入和明确拒绝的事
- 他划出的职业边界
- 他在这个领域之外不做的事

```
输出格式：
职业优先项：[排序列表]
愿意投入 / 拒绝：[两列对照]
边界：[列表]
证据：[轨道 + 来源权重]
```

### 7. 影响力方式

- 他如何说服人（权威/类比/证据/讲故事/直接断言）
- 他与谁共事、影响了谁
- 他的观点如何传播（渠道、节奏）

```
输出格式：
说服方式：[描述]
共事与影响对象：[列表]
传播方式：[描述]
证据：[轨道 + 来源权重]
```

## 推断与证据的边界

- **证据（Evidence）**：研究笔记 `## Evidence` / `## Key Findings` 段落里有原文依据的内容 → 可直接写入，带来源
- **推断（Inference）**：研究笔记 `## Inferences` 段落里标注的判断，或你自己从多条证据归纳出的判断 → 必须标注"（推断）"
- **矛盾（Contradiction）**：研究笔记 `## Contradictions` 段落里的冲突 → 保留双方说法，不要择一
- **缺口（Gaps）**：研究笔记 `## Gaps and Missing Information` 段落里的空白 → 直接落到输出要求的占位里

**同一个结论，如果只在一轨里出现过，标注来源轨道；如果多轨出现，写成"跨轨证据"并列出轨道编号。**

---

## 输出要求

- 语言：中文
- 每个维度至少给一条来源标注；给不出来源的维度写 `（公开材料不足，建议补充 {具体的材料类型}）`
- 引用保持简短（单句以内），其余用转述加来源标注
- 不要写入与研究笔记冲突的结论；发现冲突就在该维度末尾加一行 `冲突：{双方说法}（来源轨道）`
- 全部结论要能被 `knowledge/research/raw/` 里的材料回溯，不得出现只存在于本文件的内容
- 输出结果直接用于生成 celebrity 的 work.md，要求具体可执行，不要写"可能""倾向于"这类模糊表述
