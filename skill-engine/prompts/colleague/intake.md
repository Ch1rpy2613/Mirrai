# 同事材料盘点与缺口清单 Prompt

## 任务

你将收到 **{name}** 的基础信息和已导入的原材料（工作群消息、邮件、会议纪要、文档、任务单等）。

这一步**不做分析、不写 Persona**，只做两件事：

1. **盘点**：现在手上有什么材料，能支撑到什么程度
2. **点名缺口**：缺哪些材料才能构建一个可信的同事，并按优先级列出让用户去补

**原则：诚实比完整重要。宁可说"这块没材料"，也不要让后面的人格分析靠猜。**

---

## Step 0：身份确认

如果基础信息还没收集，先收集这三项（每项都可跳过）：

```
Q1 怎么称呼这位同事？（花名、昵称、代号都行，多个字用 - 连接）
   例：qing-yun / 小李 / Big Mike

Q2 用一句话说他的基本信息——公司、职级、职位、性别，想到什么写什么。
   例：字节 2-1 后端工程师 男

Q3 用一句话说他的性格——MBTI、星座、个性特点、企业文化烙印、你对他的印象。
   例：INTJ 摩羯座 甩锅高手 字节范 CR 很严格但从来不解释原因
```

解析后按下面的字段落位（缺失的留空，不要编）：

- **花名 / slug**：中文转拼音，多字用 `-` 连接
- **公司 / 职级 / 职位 / 性别**
- **MBTI / 星座**
- **个性标签**：认真负责 / 差不多就行 / 甩锅高手 / 背锅侠 / 完美主义 / 拖延症 / 直接 / 话少 / 话多 / 爱发语音 / 只读不回 / 已读乱回 / 秒回强迫症 / 果断 / 反复横跳 / 依赖上级 / 强势推进 / 数据驱动 / 全凭感觉 / 情绪稳定 / 玻璃心 / 容易激动 / 冷漠疏离 / 表面和气 / PUA 高手 / 职场政治玩家 / 甩锅艺术家 / 向上管理专家 / 阴阳怪气 / 情绪勒索 / 爱讲大道理
- **企业文化标签**：字节范 / 阿里味 / 腾讯味 / 华为味 / 百度味 / 美团味 / 第一性原理 / OKR 狂热者 / 大厂流水线 / 创业公司派
- **主观印象**：无法归类的自由描述，原样保留

如果这些信息已经在上下文里，直接复述确认，不要重复提问。

## Step 1：材料盘点

列出实际收到的材料，逐条标注类型、数量和时间跨度：

```
材料盘点：
- 工作群消息：[N] 条，时间跨度 [YYYY-MM-DD ~ YYYY-MM-DD]，涉及群 [N] 个
- 邮件：[N] 封，时间跨度 [...]
- 会议纪要 / 录音转写：[N] 份
- 文档 / 方案 / 需求单：[N] 篇
- 代码评论 / CR 记录：[N] 条
- 任务派发 / 排期记录：[N] 条
- 其他：{类型与数量}
```

要求：
- **只统计真实存在的材料**，没提供的类型直接写"无"
- 每类标注时间跨度——只有一个时间点的材料无法支撑"他一贯如何"
- 标注材料的**视角偏差**：只有他发出的消息 vs 双向对话 vs 只有别人提到他，判断不同

## Step 2：维度覆盖检查

对照 persona_analyzer.md 的 8 个维度 + work_analyzer.md 的 8 个维度，逐项给出覆盖度：

```
维度覆盖：
| 维度 | 覆盖度 | 依据 |
|------|--------|------|
| 1 角色与定位 | 充分 / 部分 / 几乎没有 | {哪份材料支撑} |
| 2 工作沟通风格 | ... |
| 3 决策模式 | ... |
| 4 反馈与评审风格 | ... |
| 5 冲突与分歧处理 | ... |
| 6 交付节奏与 deadline 行为 | ... |
| 7 协作边界与雷区 | ... |
| 8 工作节奏与职业关注点 | ... |
| W1 负责范围 | ... |
| W2 工作流程 | ... |
| W3 工具链与工作环境 | ... |
| W4 汇报线与协作关系 | ... |
| W5 质量标准与验收 | ... |
| W6 输出格式偏好 | ... |
| W7 经验知识库 | ... |
| W8 职业关注点 | ... |
```

覆盖度判定：

- **充分**：有 3 处以上互相独立的材料支撑，且分布在不同时间或不同场景
- **部分**：只有 1-2 处支撑，或全部来自单一场景（例如只有群聊记录）
- **几乎没有**：没有直接材料，只能靠手动标签推断

## Step 3：缺口清单

按"对成品的杀伤力"排序，最多列 8 条。每条必须包含：**缺什么 / 为什么重要 / 用户能提供什么形式的材料**。

```
缺口清单：
1. [高] 缺少 {具体缺口}
   为什么重要：{会导致 Persona 的哪一层只能靠猜}
   建议补充：{具体材料类型，例如"3 次被催进度的对话"或"2 份他写的技术方案"}
2. [中] ...
```

覆盖缺口时，**同一份材料可以补多个维度**，所以排优先级时看的是"补完能点亮几层"，不是"缺得多不多"。

如果某维度缺口无法通过追加材料补齐（例如"他和上级的分歧"这种用户也不会有材料），直接标注"无法补充"，后续在 Persona 里按"原材料不足"处理，不要反复追问。

## 规则

- 语言：中文
- 不要在盘点阶段做任何性格推断或写任何 Layer 内容
- 不要把"没提供"当成"没有"——区分**材料里不存在**和**材料里没提到**
- 缺口清单要给到可执行粒度（"更多聊天记录"不算，"他被催进度时的 3 条回复"才算）
- 如果材料总量已经足够支撑所有维度，直接说明可以开始，不要硬凑缺口
